# TourHome

סיורי וידאו קצרים בדירות להשכרה ולמכירה — פיד אנכי בסגנון רשתות חברתיות, רק לדירות.

**האתר:** https://ronco-c.github.io/tourhome/

## מה יש באפליקציה
- פיד וידאו אנכי עם חלוקה לחדרים (קפיצה ישירה לסלון, מטבח, מרפסת…)
- העלאה בשלושה שלבים: סרטון → סימון חדרים → פרטי הנכס
- סינון לפי אזור, עיר (השלמה אוטומטית), מחיר, חדרים ומאפיינים
- לשונית מתווכים, מסלולי TourHome Business, קידום מודעות וסטטיסטיקה לפי חדר
- מחשבון משכנתא, שירותים למעבר, חיפושים שמורים עם התראות

## מצב נוכחי
אב־טיפוס: קובץ `index.html` אחד, בלי שרת. הנתונים נשמרים במכשיר של המשתמש בלבד (IndexedDB).
השלב הבא: שרת (Supabase) כדי שכל המשתמשים יראו את אותן מודעות.

## הגדרות
בראש הסקריפט ב־`index.html`:
- `BUSINESS_WHATSAPP` — מספר וואטסאפ עסקי לקבלת לידים (למשל `972501234567`)
- `PLANS`, `BOOSTS` — מחירי המסלולים והקידומים
